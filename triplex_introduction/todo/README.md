# Todo / Backlog

This folder tracks pending and in-progress work in the Triplex project.

## How to Log a Task

Create a new file: `TODO-XXX-short-description.md`

Use this template:

```markdown
# TODO-XXX: Short Description

**Date Created:** YYYY-MM-DD
**Created By:** [human | agent]
**Status:** Backlog | In Progress | Done | Cancelled
**Affects:** [feature name, e.g. feed, auth, map]
**Priority:** High | Medium | Low

---

## Goal
What this task should accomplish.

## Acceptance Criteria
- [ ] Criterion 1
- [ ] Criterion 2

## Notes
Any relevant context, links, or constraints.

## Progress Log
- YYYY-MM-DD: (what was done)
```
