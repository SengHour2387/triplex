# Bugs

This folder tracks known bugs in the Triplex project.

## How to File a Bug

Create a new file: `BUG-XXX-short-description.md`

Use this template:

```markdown
# BUG-XXX: Short Description

**Date Found:** YYYY-MM-DD
**Reported By:** [human | agent]
**Status:** Open | In Progress | Resolved
**Affects:** [feature name, e.g. feed, auth, map]
**Severity:** Critical | High | Medium | Low

---

## Description
What is happening.

## Steps to Reproduce
1. Step 1
2. Step 2

## Expected Behavior
What should happen.

## Root Cause
(Fill in when known)

## Fix
(Fill in when resolved — include the commit/PR or file changed)
```
